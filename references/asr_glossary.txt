# ASR 专名误识对照表
#
# 用途：转写（whisper / funasr-nano / B站 AI 字幕）都会把专名听错，其中一类
# 错误尤其危险——**误识结果本身是合法中文词**，AI 读到时根本不会起疑，
# 于是错误写法一路带进正文、带进 frontmatter 的 entities，把正确名的检索入口堵死。
#
# 本表就是为这类"看起来没毛病"的误识准备的强制纠错清单。
#
# 格式（3 列，竖线分隔，# 开头为注释，空行忽略）：
#   错误写法 | 正确写法 | 语境限定与说明
#
# 使用规则（详见 SKILL.md「专名误识硬规则」）：
#   1. 生成纪要**之前**先查本表，命中即按正确写法写入正文
#   2. 正确写法要进 entities / tags；**错误写法一律不得进 entities**
#   3. 「语境限定」写明 ALL 的必须无条件替换；写明具体语境的，
#      只在命中该语境时替换（历史类内容里的"尧舜禹"是本义，不能动）
#   4. 写完跑 scripts/check_glossary.py 兜底复核
#
# 新增词条前先想清楚：这个词会不会在正常语境下合法出现？会 → 必须写语境限定。
#
# ⚠️ 本表只收「强制」条目。仅是提示、写法可接受的，不要放进本表——它们会被每次扫描报为
#    「需判语境」命中，永报不修，稀释扫描结果的可信度。这类条目放 专名误识速查-主题组.txt。
